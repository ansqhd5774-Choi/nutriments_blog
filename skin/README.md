# 현재 운영 스킨

2026-10-04 공식 티스토리 스킨 편집 화면에서 원본을 확보했습니다. skin.html은 description 공통 태그 한 줄만 제거한 적용본이고 style.css는 원본 그대로입니다. 이미지·JS 등 전체 스킨 패키지는 포함하지 않습니다.

GitHub 글 발행 workflow는 스킨을 자동 적용하지 않습니다. 스킨 변경은 GitHub 검토 후 공식 스킨 편집에서 동일 소스를 적용하고 공개 페이지를 확인합니다.

되돌리기: `<meta name="description" content="[##_desc_##]" />`를 description 관련 주석 위치에 복구합니다. 전체 원본은 로컬 private 백업에 보존했습니다.
